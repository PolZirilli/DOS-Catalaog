Poné acá los bundles `.jsdos` de los juegos que empaquetes localmente (en vez
de hostearlos en otro lado), y apuntá el campo `"bundle"` de
`data/games.json` a `"games/<archivo>.jsdos"`.

Ver el README principal del proyecto para cómo generar un `.jsdos` a partir
de un juego que ya tengas (CD original, instalador DRM-free, etc.).
