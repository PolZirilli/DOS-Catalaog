Poné acá los íconos reales de cada juego, con el nombre `<id>.png` usando el
mismo `id` que la entrada correspondiente en `data/games.json`.

Ejemplo: para el juego `{"id":"quake", ...}` el archivo va en `icons/quake.png`.

Si no existe el archivo, el catálogo cae automáticamente a una placa con las
iniciales del juego — no rompe nada, así que se puede ir completando de a poco.
